Templates live at the repo root and under `apps/*` / `packages/*`. Copy each `.env.example` to `.env.local`.

## Web App (`apps/web`)

Create `apps/web/.env.local`:

| Variable                     | Required | Description                                                          |
| ---------------------------- | -------- | -------------------------------------------------------------------- |
| `VITE_CONVEX_URL`            | Yes      | Convex deployment URL (e.g. `https://happy-animal-123.convex.cloud`) |
| `VITE_CLERK_PUBLISHABLE_KEY` | Yes      | Clerk publishable key (starts with `pk_`)                            |

## Convex Backend (`packages/backend`)

Set these in the **Convex dashboard** (Settings → Environment Variables). The same names are in `packages/backend/.env.example` for local CLI tests.

| Variable                 | Required | Description                                                              |
| ------------------------ | -------- | ------------------------------------------------------------------------ |
| `CLERK_FRONTEND_API_URL` | Yes      | Clerk JWKS domain for Convex auth                                        |
| `CLERK_SECRET_KEY`       | Yes      | Clerk secret key (MCP OAuth token verify)                                |
| `CLERK_PUBLISHABLE_KEY`  | Yes      | Clerk publishable key (MCP token verify)                                 |
| `ENCRYPTION_KEY`         | Yes      | Base64-encoded AES-256 key for API key encryption                        |
| `CONVEX_SITE_URL`        | Yes      | Your `.convex.site` URL (OAuth redirects)                                |
| `WEB_APP_URL`            | Yes      | Web app origin (MCP OAuth callbacks)                                     |
| `OPENROUTER_API_KEY`     | No       | Embeddings / fact extraction (Convex deployment env only)                |
| `TYPESAFE_API_KEY`       | No       | TypeSafe Jev retrieve rerank and Dream Mode merge metadata (on when set) |

There is **no** in-app Settings → Secrets page. Operators set `OPENROUTER_API_KEY` and `TYPESAFE_API_KEY` on the Convex deployment (dashboard Environment Variables or `npx convex env set`). Instruction `save` / `update` over HTTP return `422 openrouter_required` when `OPENROUTER_API_KEY` is missing from the deployment.

Optional Jev retrieve rerank and Dream Mode near-duplicate merge metadata: set `TYPESAFE_API_KEY` on the Convex deployment. Retrieve reranks automatically (no noul hard-drop). Dream Mode always creates a proposal for each heuristic cluster; Jev may override the keeper and the auto-accept signal. Missing key fail-opens to hybrid retrieve / heuristic merge (no 422). HTTP/SDK retrieve may pass `judge: "off"` for labelled ablation; LoCoMo CLI uses `LOCOMO_IR_JUDGE`. Live MCP retrieve does not expose that flag. Enablement notes live in `packages/backend/tests/memory/jev-retrieve-gate.md`.

There is **no** `NEO4J_*` or `MCP_JWT_SECRET` on current `main`.

### Connector OAuth (optional)

| Variable                                    | Integration  |
| ------------------------------------------- | ------------ |
| `GOOGLE_CLIENT_ID` / `GOOGLE_CLIENT_SECRET` | Google Drive |
| `NOTION_CLIENT_ID` / `NOTION_CLIENT_SECRET` | Notion       |

Also required for OAuth callbacks: `CONVEX_SITE_URL`.

## Chrome Extension

Copy `apps/chrome-extension/.env.example` to `.env.local` before `pnpm ext:build`:

| Variable                     | Description                           |
| ---------------------------- | ------------------------------------- |
| `VITE_CONVEX_URL`            | Convex deployment URL                 |
| `VITE_CLERK_PUBLISHABLE_KEY` | Clerk publishable key                 |
| `VITE_CLERK_SYNC_HOST`       | Web origin used for Clerk cookie sync |

If env is omitted, the extension falls back to constants in `apps/chrome-extension/src/lib/constants.ts`.

## SDK / HTTP scripts

Root `.env.example` / `packages/sdk/.env.example`:

```
VMEM_API_KEY=vmem_sk_...
VMEM_BASE_URL=https://your-deployment.convex.site
```

## Generating ENCRYPTION_KEY

```bash
node -e "console.log(require('crypto').randomBytes(32).toString('base64'))"
```

Copy the output into your Convex environment variables.
