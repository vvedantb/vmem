Convex functions in `profiles`.

## List Profiles

Returns personal profiles owned by the user plus team profiles for teams the user belongs to.

```typescript
await client.query(api.profiles.list, {});
```

---

## Get Profile

<ParamField body="profileId" type="string" required />

```typescript
await client.query(api.profiles.get, { profileId: "profile_abc" });
```

---

## Get or Create Default

Ensures the user has an active default profile. Creates one if missing.

```typescript
await client.mutation(api.profiles.getOrCreateDefault, {});
```

---

## Create Profile

<ParamField body="name" type="string" required />
<ParamField body="color" type="string" required />
<ParamField body="icon" type="string" required />

```typescript
await client.mutation(api.profiles.create, {
  name: "Work",
  color: "#3b82f6",
  icon: "briefcase",
});
```

---

## Update Profile

<ParamField body="profileId" type="string" required />
<ParamField body="name" type="string" />
<ParamField body="color" type="string" />
<ParamField body="icon" type="string" />

```typescript
await client.mutation(api.profiles.update, {
  profileId: "profile_abc",
  name: "Personal",
});
```

---

## Remove Profile

<ParamField body="profileId" type="string" required />
<ParamField body="moveMemoriesToProfileId" type="string">
  Profile to move existing memories to before deletion
</ParamField>

```typescript
await client.mutation(api.profiles.remove, {
  profileId: "profile_abc",
  moveMemoriesToProfileId: "profile_def",
});
```

---

## Remove Profile with Memories

Deletes the profile and all its memories.

<ParamField body="profileId" type="string" required />
<ParamField body="moveMemoriesToProfileId" type="string">
  Optional — move memories instead of deleting
</ParamField>

See [Profiles concept](/concepts/profiles) for usage patterns.
