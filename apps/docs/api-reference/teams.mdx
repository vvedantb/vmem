---
title: "Teams"
description: "Create and manage teams with shared memory profiles"
---

Convex functions in `teams`.

## List Teams

```typescript
await client.query(api.teams.list, {});
```

---

## Get Team

<ParamField body="teamId" type="string" required />

```typescript
await client.query(api.teams.get, { teamId: "team_abc" });
```

---

## Create Team

Creates a team and its associated profile.

<ParamField body="name" type="string" required />

```typescript
await client.mutation(api.teams.create, { name: "Engineering" });
```

---

## Update Team

<ParamField body="teamId" type="string" required />
<ParamField body="name" type="string" required />

```typescript
await client.mutation(api.teams.updateTeam, {
  teamId: "team_abc",
  name: "Platform Engineering",
});
```

---

## Add Member

Invite a user by email. They must have a vmem account.

<ParamField body="teamId" type="string" required />
<ParamField body="email" type="string" required />

```typescript
await client.mutation(api.teams.addMember, {
  teamId: "team_abc",
  email: "colleague@example.com",
});
```

---

## Remove Member

<ParamField body="teamId" type="string" required />
<ParamField body="userId" type="string" required />

```typescript
await client.mutation(api.teams.removeMember, {
  teamId: "team_abc",
  userId: "user_xyz",
});
```

---

## Leave Team

```typescript
await client.mutation(api.teams.leaveTeam, { teamId: "team_abc" });
```

---

## Delete Team

Permanently deletes the team and its profile.

<ParamField body="teamId" type="string" required />

```typescript
await client.mutation(api.teams.deleteTeam, { teamId: "team_abc" });
```

See [Teams feature](/features/teams) for the full workflow and memory permissions.
