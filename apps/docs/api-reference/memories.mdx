title: "Memories"

All functions are Convex `authAction`s in `memoryApi`. Call via `client.action(api.memoryApi.<name>, args)`.

## Create Memory

<ParamField body="title" type="string" required>
  Short title for the memory
</ParamField>
<ParamField body="content" type="string" required>
  The memory content
</ParamField>
<ParamField body="type" type="string" required>
  One of: `profile`, `episodic`, `knowledge`
</ParamField>
<ParamField body="source" type="string" required>
  Where the memory originated (e.g. `manual`, `mcp`, `chatgpt`)
</ParamField>
<ParamField body="tags" type="string[]" required>
  Tags for categorisation
</ParamField>
<ParamField body="confidence" type="number" required>
  Confidence score between 0 and 1
</ParamField>
<ParamField body="profileId" type="string">
  Profile to save to (defaults to active profile)
</ParamField>
<ParamField body="expiresAt" type="string">
  ISO 8601 expiry date
</ParamField>
<ParamField body="externalId" type="string">
  Stable upstream identifier for idempotent imports
</ParamField>
<ParamField body="sourceType" type="string">
  Source type paired with `externalId` for deduplication
</ParamField>

```typescript
await client.action(api.memoryApi.createMemory, {
  title: "Preferred stack",
  content: "User prefers Next.js with Convex backend",
  type: "profile",
  source: "manual",
  tags: ["tech", "preferences"],
  confidence: 0.95,
});
```

**Returns:** `MemoryWithTags`

## Delete All Memories

Irreversible. Deletes every memory owned by the calling user plus all dependents (chunks, events, proposed updates, entities).

```typescript
await client.action(api.memoryApi.deleteAllMemories, {});
```

**Returns:** `number` (count of deleted memories)

## Retrieve Memories

Semantic retrieval with context trace scoring. Also returns user settings context in parallel.

<ParamField body="query" type="string" required>
  Natural language query
</ParamField>
<ParamField body="limit" type="number" required>
  Max results (typically 5–8)
</ParamField>
<ParamField body="type" type="string">
  Filter by memory type
</ParamField>
<ParamField body="tags" type="string[]">
  Filter by tags
</ParamField>

```typescript
await client.action(api.memoryApi.retrieveMemories, {
  query: "What tech stack does the user prefer?",
  limit: 8,
});
```

**Returns:**

```typescript
{
  memories: MemoryCandidate[];  // includes trace + optional matchedChunk
  userContext: {
    aboutMe: string | null;
    preferences: string | null;
  };
}
```

See [Context Trace](/concepts/context-trace) for score breakdown details.

## Generate Upload URL

Returns a signed URL for uploading a file to Convex storage. Valid for ~1 hour.

```typescript
const url = await client.mutation(api.memoryApi.generateMemoryUploadUrl, {});
```

**Returns:** `string` (upload URL)

## Team-Scoped Memories

Team memory operations require a `profileId` (the team's profile Convex ID):

| Function             | Description                     |
| -------------------- | ------------------------------- |
| `listTeamMemories`   | List memories on a team profile |
| `getTeamMemory`      | Get a single team memory        |
| `searchTeamMemories` | Search team memories            |
| `updateTeamMemory`   | Update (creator or team owner)  |
| `deleteTeamMemory`   | Delete (creator or team owner)  |

All verify team membership before hitting Neo4j. See [Teams](/features/teams).
