## Create Memory

<ParamField body="userId" type="string" required>
  The user ID to associate the memory with
</ParamField>
<ParamField body="title" type="string" required>
  Short title for the memory
</ParamField>
<ParamField body="content" type="string" required>
  The memory content
</ParamField>
<ParamField body="type" type="string" required>
  One of: `profile`, `episodic`, `knowledge`
</ParamField>
<ParamField body="source" type="string">
  Where the memory originated (e.g., `manual`, `mcp`, `api`)
</ParamField>
<ParamField body="tags" type="string[]">
  Tags for categorisation
</ParamField>
<ParamField body="confidence" type="number">
  Confidence score between 0 and 1
</ParamField>
<ParamField body="expiresAt" type="string">
  ISO 8601 expiry date
</ParamField>

```bash
POST /v1/memories
```

```json
{
  "userId": "user_123",
  "title": "Preferred stack",
  "content": "User prefers Next.js with Convex backend",
  "type": "profile",
  "source": "manual",
  "tags": ["tech", "preferences"],
  "confidence": 0.95
}
```

**Response:** `201 Created` with the full memory object.

## Get Memory Events


Returns `{ "events": [...] }` — the full history of creates, updates, and status changes.
