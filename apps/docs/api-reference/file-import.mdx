Convex `authAction`s in `fileImport`.

## Import Memory from File

Process an uploaded file (PDF, text) into a memory.

<ParamField body="storageId" type="string" required>
  Convex storage ID from upload
</ParamField>
<ParamField body="filename" type="string" required />
<ParamField body="mimeType" type="string" required />
<ParamField body="profileId" type="string">
  Profile to save to (defaults to active)
</ParamField>

```typescript
await client.action(api.fileImport.importMemoryFromFile, {
  storageId: "storage_abc",
  filename: "notes.pdf",
  mimeType: "application/pdf",
});
```

## Import Image Memory

Create a memory from an uploaded image with optional page context.

<ParamField body="storageId" type="string" required />
<ParamField body="mimeType" type="string" required />
<ParamField body="caption" type="string">
  Optional image caption
</ParamField>
<ParamField body="pageUrl" type="string">
  Source page URL
</ParamField>
<ParamField body="pageTitle" type="string">
  Source page title
</ParamField>
<ParamField body="profileId" type="string" />

```typescript
await client.action(api.fileImport.importImageMemory, {
  storageId: "storage_abc",
  mimeType: "image/png",
  pageUrl: "https://example.com/article",
  pageTitle: "Example Article",
});
```

## Upload Flow

1. Call `memoryApi.generateMemoryUploadUrl` to get a signed upload URL
2. POST the file to the URL
3. Receive `{ storageId }` from Convex
4. Call `importMemoryFromFile` or `importImageMemory` with the storage ID

See [Import feature](/features/import) for the web UI workflow.
