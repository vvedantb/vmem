Convex `authAction`s in `proposedUpdateApi`.

## List Proposed Updates

Returns all pending and resolved proposals for the authenticated user.

```typescript
await client.action(api.proposedUpdateApi.listProposedUpdates, {});
```

**Returns:** `ProposedUpdateNode[]`

```typescript
interface ProposedUpdateNode {
  id: string;
  memoryId: string;
  proposedContent: string;
  proposedTitle: string | null;
  reason: string;
  kind: "update" | "delete" | "insight" | "connection" | "contradiction" | "anomaly";
  status: string;
  createdAt: string;
  resolvedAt: string | null;
  sourceMemoryIds: string[];
  confidence: number | null;
  source: "v2-extraction" | "dream-mode";
  memorySnapshot: { title: string; content: string } | null;
  sourceMemorySnapshots: { id: string; title: string; content: string }[];
}
```

---

## Resolve Proposal

Approve or reject a pending proposal.

<ParamField body="proposalId" type="string" required>
  The proposal ID
</ParamField>
<ParamField body="action" type="string" required>
  `"approve"` or `"reject"`
</ParamField>

```typescript
await client.action(api.proposedUpdateApi.resolveProposal, {
  proposalId: "proposal_abc",
  action: "approve",
});
```

**Returns:**

```typescript
{
  status: string;
  memoryId: string;
  kind: ProposedUpdateKind;
  materializedMemoryId?: string; // set when approve creates a new memory (synthesis kinds)
}
```

### Behavior by Kind

| Kind | Approve | Reject |
| --- | --- | --- |
| `update` | Replace memory content | Original preserved |
| `delete` | Hard-delete memory | Original preserved |
| `insight` | Materialize new memory | Proposal discarded |
| `connection` | Create relationship edge | Proposal discarded |
| `contradiction` | Flag for review | Proposal discarded |
| `anomaly` | Surface anomaly | Proposal discarded |

See [Proposed Updates concept](/concepts/proposed-updates) for the full lifecycle.
