description: "Memory statistics and activity data"
---

Convex `authAction`s in `dashboardApi`.

## Get Stats

Returns aggregate statistics for the authenticated user's memory collection.

<ParamField body="profileId" type="string">
  Optional profile filter
</ParamField>

```typescript
await client.action(api.dashboardApi.getStats, {});
```

**Returns:** counts such as `totalMemories`, period totals, tag totals, and a `growthData` series.

---

## Get Recent Activity

Returns recent memory activity for the authenticated user.

<ParamField body="limit" type="number">
  Max items to return
</ParamField>

```typescript
await client.action(api.dashboardApi.getRecentActivity, { limit: 20 });
```

**Returns:** `ActivityItem[]` with `id`, `type`, `title`, `description`, `timestamp`, `relativeTime`.

Dashboard stats in the sidebar always show user-wide totals, not filtered by the active profile.
