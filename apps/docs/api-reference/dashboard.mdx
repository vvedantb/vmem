---
title: "Dashboard"
description: "Memory statistics and activity data"
---

Convex `authAction`s in `dashboardApi`. Results are cached for 30 seconds.

## Get Stats

Returns aggregate statistics for the authenticated user's memory collection.

<ParamField body="profileId" type="string">
  Optional profile filter
</ParamField>

```typescript
await client.action(api.dashboardApi.getStats, {});
```

**Returns:**

```json
{
  "totalMemories": 142,
  "memoriesThisWeek": 12,
  "memoriesThisMonth": 45,
  "memoriesAddedToday": 3,
  "totalTags": 28,
  "growthData": [
    { "date": "2026-05-01", "total": 100, "new": 5 },
    { "date": "2026-05-02", "total": 105, "new": 5 }
  ]
}
```

---

## Get Profiles Stats

Returns per-profile memory counts.

<ParamField body="profileIds" type="string[]" required>
  Array of profile IDs to fetch stats for
</ParamField>

```typescript
await client.action(api.dashboardApi.getProfilesStats, {
  profileIds: ["profile_abc", "profile_def"],
});
```

---

## Get Recent Activity

Returns recent memory activity for the authenticated user.

<ParamField body="limit" type="number">
  Max items to return
</ParamField>

```typescript
await client.action(api.dashboardApi.getRecentActivity, { limit: 20 });
```

**Returns:** `ActivityItem[]`

```typescript
interface ActivityItem {
  id: string;
  type: string;
  title: string;
  description: string;
  timestamp: string;
  relativeTime: string;
}
```

Dashboard stats in the sidebar always show user-wide totals, not filtered by the active profile.
