## Prerequisites

- Node.js 20+
- pnpm 10+
- A [Convex](https://convex.dev) account
- A [Clerk](https://clerk.com) application
- A [Neo4j Aura](https://neo4j.com/cloud/aura/) instance (or local Neo4j)

## 1. Clone and Install

```bash
git clone https://github.com/vedantbhopatrao/vmem.git
cd vmem
pnpm install
```

## 2. Configure Environment

See [Environment Variables](/environment) for the full list. At minimum you need:

**Web app** — create `apps/web/.env.local`:

```env
VITE_CONVEX_URL=https://your-deployment.convex.cloud
VITE_CLERK_PUBLISHABLE_KEY=pk_test_...
```

**Backend** — set in the Convex dashboard (Settings → Environment Variables):

```env
CLERK_FRONTEND_API_URL=https://your-clerk-domain.clerk.accounts.dev
CLERK_SECRET_KEY=sk_test_...
ENCRYPTION_KEY=<base64-encoded AES-256 key>
MCP_JWT_SECRET=<random secret for MCP tokens>
NEO4J_URI=neo4j+s://your-instance.neo4j.io
NEO4J_PASSWORD=your-password
```

**Neo4j local scripts** — create `packages/backend/.env.local` for seed/eval commands:

```env
NEO4J_URI=neo4j+s://your-instance.neo4j.io
NEO4J_USERNAME=neo4j
NEO4J_PASSWORD=your-password
```

## 3. Start the Backend

```bash
pnpm convex
```

This runs `npx convex dev` for the `@vmem/backend` package and syncs functions to your Convex deployment.

## 4. Start the Web App

In a second terminal:

```bash
pnpm dev
```

Open the URL Vite prints (typically `http://localhost:5173`). Sign in with Clerk to create your user record.

## 5. Create Your First Memory

Use the web dashboard:

1. Go to **Memories** in the sidebar
2. Click **Add memory**
3. Fill in title, content, and type (`profile`, `episodic`, or `knowledge`)
4. Save

Or use the MCP Playground at `/settings/playground` to call the `memory_add` tool.

## 6. Connect an MCP Client

Add vmem as a remote MCP connector in Claude (Settings → Connectors) or Cursor:

```
https://<your-deployment>.convex.site/mcp
```

Copy the full `.convex.site` URL from your Convex dashboard. Sign in with your vmem account when prompted.

The `vmem://context_prompt` resource is injected automatically at conversation start — no tool call required.

## 7. Optional: Chrome Extension

```bash
pnpm ext:build
```

Load `apps/chrome-extension/dist/` as an unpacked extension in Chrome (`chrome://extensions` → Developer mode → Load unpacked).

## 8. Optional: Mobile App

```bash
cp apps/mobile/.env.example apps/mobile/.env
# Fill in EXPO_PUBLIC_CONVEX_URL and EXPO_PUBLIC_CLERK_PUBLISHABLE_KEY
pnpm mobile
```
