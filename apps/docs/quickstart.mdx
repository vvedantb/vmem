## Prerequisites

- Node.js 20+
- pnpm 10.15.1
- A [Convex](https://convex.dev) account
- A [Clerk](https://clerk.com) application

You do not need Neo4j. Memories are stored in Convex.

## 1. Clone and Install

```bash
git clone https://github.com/vvedantb/vmem.git
cd vmem
pnpm install
```

## 2. Configure Environment

See [Environment Variables](/environment) for the full list. At minimum:

**Web app** — create `apps/web/.env.local`:

```env
VITE_CONVEX_URL=https://your-deployment.convex.cloud
VITE_CLERK_PUBLISHABLE_KEY=pk_test_...
```

**Backend** — set in the Convex dashboard (Settings → Environment Variables), and copy `packages/backend/.env.example` to `packages/backend/.env.local` for local CLI tests:

```env
CLERK_FRONTEND_API_URL=https://your-clerk-domain.clerk.accounts.dev
CLERK_SECRET_KEY=sk_test_...
CLERK_PUBLISHABLE_KEY=pk_test_...
ENCRYPTION_KEY=<base64-encoded AES-256 key>
CONVEX_SITE_URL=https://your-deployment.convex.site
WEB_APP_URL=http://localhost:5173
OPENROUTER_API_KEY=sk-or-...
```

Generate `ENCRYPTION_KEY` with:

```bash
node -e "console.log(require('crypto').randomBytes(32).toString('base64'))"
```

## 3. Start the Backend

```bash
pnpm convex
```

This runs `npx convex dev` for the `@vmem/backend` package and syncs functions to your Convex deployment.

## 4. Start the Web App

In a second terminal:

```bash
pnpm dev
```

Open the URL Vite prints (typically `http://localhost:5173`). Sign in with Clerk to create your user record.

## 5. Create Your First Memory

Use the web dashboard:

1. Go to **Memories** in the sidebar
2. Click **Add memory**
3. Fill in title, content, and type (`profile`, `episodic`, or `knowledge`)
4. Save

## 6. Connect an MCP Client

Add vmem as a remote MCP connector in Claude (Settings → Connectors) or Cursor:

```
https://<your-deployment>.convex.site/mcp
```

Copy the full `.convex.site` URL from your Convex dashboard. Sign in with your vmem account when prompted.

The `vmem://context_prompt` resource is injected automatically at conversation start — no tool call required.

## 7. Optional: Chrome Extension

```bash
cp apps/chrome-extension/.env.example apps/chrome-extension/.env.local
# fill VITE_CONVEX_URL, VITE_CLERK_PUBLISHABLE_KEY, VITE_CLERK_SYNC_HOST
pnpm ext:build
```

Load `apps/chrome-extension/dist/chrome-mv3/` as an unpacked extension in Chrome (`chrome://extensions` → Developer mode → Load unpacked). Dev watch output is `dist/chrome-mv3-dev/`.

## 8. Optional: Docs site

```bash
pnpm docs:dev
```

Mintlify preview at `http://localhost:3001`. Requires the `mint` CLI.
