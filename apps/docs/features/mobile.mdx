## Overview

The vmem mobile app (`apps/mobile`) is an Expo React Native app with Clerk auth, Convex live data, and offline local LLM chat with memory retrieval.

## Setup

```bash
cp apps/mobile/.env.example apps/mobile/.env
```

Fill in:

```env
EXPO_PUBLIC_CONVEX_URL=https://your-deployment.convex.cloud
EXPO_PUBLIC_CLERK_PUBLISHABLE_KEY=pk_test_...
```

Start the dev server:

```bash
pnpm mobile
```

For Android:

```bash
pnpm android
```

## Chat with Memories

The mobile chat provider follows this pattern:

1. Call `memoryApi.retrieveMemories` before each turn
2. Inject memories into the system prompt
3. Stream response from local model
4. Show memory reference badges under assistant messages

## Offline Mode

When offline, the app shows an "Offline mode — using local AI" banner. Chat requires a downloaded local model; without one, the UI prompts you to download a model in Settings.
