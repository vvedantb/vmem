## Overview

Teams let multiple users share a memory profile for company knowledge. Each team has one profile; all members can read and write memories on it.

Teams live in the sidebar workspace switcher; a team workspace has Members and Team settings pages under `/{workspace}/team/`.

## Creating a Team

1. Go to **Teams** in the sidebar
2. Click **Create team**
3. Enter a team name
4. A team profile is created automatically

## Team Members

Team owners can invite members by email. Members get read/write access to the team profile's memories.

| Action | Who |
| --- | --- |
| View team memories | Any member |
| Create memories | Any member |
| Update own memories | Original creator |
| Update any memory | Team owner |
| Delete own memories | Original creator |
| Delete any memory | Team owner |
| Invite/remove members | Team owner |

Creator attribution is preserved on each memory and surfaced in the UI.

## Team Memories API

Team-scoped memory operations use separate Convex actions:

- `memoryApi.listTeamMemories`
- `memoryApi.getTeamMemory`
- `memoryApi.searchTeamMemories`
- `memoryApi.updateTeamMemory`
- `memoryApi.deleteTeamMemory`

All require a `profileId` (the team's profile ID) and verify team membership before hitting Neo4j.

See [Teams API Reference](/api-reference/teams) and [Memories API](/api-reference/memories#team-scoped-memories).

## Profiles

Team profiles appear alongside personal profiles in the profile dropdown. Switching to a team profile changes where new memories are saved.

Dashboard stats always show user-wide totals, not filtered by team profile.
