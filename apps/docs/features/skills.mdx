## Overview

Skills are reusable instruction modules — a name, description, and markdown instructions that AI agents can consult during conversations.

Route: `/skills`

## Creating a Skill

1. Go to **Skills** in the sidebar
2. Click **Create skill**
3. Enter name, description, and markdown instructions
4. Save

Skills are stored in Convex and associated with your user account.

## MCP Integration

Skills appear in the **Available Skills** section of the `vmem://context_prompt` MCP resource (refreshed when skills change). MCP clients also have:

| Tool | Description |
| --- | --- |
| `skills_list` | List enabled skills (name + description only) |
| `skills_get` | Fetch a single skill by exact name, including full markdown instructions |
| `skills_create` | Create a new skill (name, description, markdown instructions) |

When a task matches a skill's description, call `skills_get` to load full instructions before following them.

## Local Chat & Voice

The skills index is injected into every local chat and voice system prompt. When your message mentions a skill by name, its full instructions are loaded for that turn automatically (no MCP tools in local mode).
