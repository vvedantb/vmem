## Overview

Skills are reusable instruction modules — a name, description, and markdown instructions that AI agents can consult during conversations.

Route: `/{workspace}/skills`

## Creating a Skill

1. Go to **Skills** in the sidebar
2. Click **Create skill**
3. Enter name, description, and markdown instructions
4. Save

Skills are stored in Convex and associated with your user account.

## MCP Integration

Skills appear in the **Available Skills** section of the `vmem://context_prompt` MCP resource (refreshed when skills change). Each enabled skill is also an MCP resource at `vmem://skills/<name>`. MCP clients also have:

| Tool               | Description                                                                                                         |
| ------------------ | ------------------------------------------------------------------------------------------------------------------- |
| `skills_list`      | List enabled skills granted to this connector (name + description only)                                             |
| `skills_recommend` | Shortlist skills for a task/query via TypeSafe Jev (fail-open to lexical match if the key is missing)               |
| `skills_get`       | Fetch a single skill by exact name, including full markdown instructions                                            |
| `skills_create`    | Create a skill when a repeatable problem or automatable workflow was identified and no existing skill covers it yet |
| `skills_update`    | Update an existing skill when its playbook should change (refinement, rename, disable)                              |

Call `skills_recommend` (or `skills_list`) at task start, then `skills_get` for matching names. Do not bulk-load every playbook. The bootstrap system skill `search-skills-first` is always in the Available Skills index with that workflow.

### Grants

- Personal `/mcp`: the caller's personal skills (`teamId` unset) plus always-on system skills.
- Team `/mcp/team`: only skills granted to the active team profile (membership is the grant). Personal skills never leak here, and team skills never leak to `/mcp`.
