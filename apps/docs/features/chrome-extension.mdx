## Overview

The vmem Chrome extension connects your browser to your vmem account. Save pages, export conversations, inject memories into AI chats, and bulk-import bookmarks and history.

## Installation

```bash
pnpm ext:build
```

Load `apps/chrome-extension/dist/` as an unpacked extension:

1. Open `chrome://extensions`
2. Enable **Developer mode**
3. Click **Load unpacked**
4. Select the `dist/` folder

For development with auto-rebuild:

```bash
pnpm ext:dev
```

Update Convex URL and Clerk key in `apps/chrome-extension/src/lib/constants.ts` before building.

## Features

### Export to vmem

Button injected into ChatGPT and Claude conversation pages. Exports the full conversation as episodic memories via Convex `memoryApi.createMemory`.

### Use vmem

Retrieves relevant memories for your current message and prepends them as context before you send. Works on ChatGPT and Claude.

### Save Page

Right-click context menu or popup button to save any web page as a knowledge memory.

### Import Bookmarks

Bulk import browser bookmarks as knowledge memories from the extension popup.

### Import History

Bulk import browsing history as episodic memories.

## Authentication

The extension uses the same Clerk auth as the web app via `ConvexHttpClient` and `api.memoryApi.*` actions.

## Enrichment

Memories saved from the extension are enriched automatically server-side (tags, related memories, entities). See [Enrichment](/concepts/enrichment).

## Settings

Configure the extension from the web dashboard at **Settings → Extension** (`/settings/extension`).
