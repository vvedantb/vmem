title: "MCP Tools"
description: "Complete reference for all vmem MCP tools"
---

Tools are registered from `packages/backend/convex/mcp/tools*.ts`. Auth accepts a Clerk `oauth_token` or `session_token` bearer (MCP server `2.1.0`). Memory tools work on `/mcp` and `/mcp/team`. Skills tools also work on both connectors (personal skills on `/mcp`, team-granted skills on `/mcp/team`), except `skills_import` which is personal `/mcp` only. `proposals_list` and `proposals_resolve` work on both connectors. Files, `context_prompt_get`, `dream_run` and the `notifications_*` tools are personal-only.

Every tool acts as the signed-in user from the bearer token. No tool takes a user ID. IDs that belong to another user, or to a profile outside the connector, return "not found".

## context_pack

One call at task start. Returns a markdown pack with the memories that best fit the task, the best-fit skills, and the user profile. Works on `/mcp` and `/mcp/team`; the profile section is personal-only.

Sections fill in priority order until `maxChars`: relevant memories (same retrieve and Jev rerank as `memory_retrieve`), suggested skills (same as `skills_recommend`), then the profile from `context_prompt_get` without its skills index. The top memory is always included. If the skills or profile lookup fails, that section is left out and the pack still returns.

<ParamField body="task" type="string" required>
  The user's current task or question
</ParamField>
<ParamField body="profileId" type="string">
  Profile to pack memories from (defaults to active profile)
</ParamField>
<ParamField body="memoryLimit" type="number">
  Max memories, 1–20 (default 8)
</ParamField>
<ParamField body="skillLimit" type="number">
  Max suggested skills, 0–8 (default 3; 0 skips skills)
</ParamField>
<ParamField body="maxChars" type="number">
  Character budget, 1000–32000 (default 8000)
</ParamField>
<ParamField body="referenceDate" type="string">
  ISO date used as “now” for temporal scoring
</ParamField>

**Returns:** `{ markdown, memoryIds, skillNames, includesProfile, truncated, skillSource }`. `truncated` is `true` when the budget cut a memory, skill, or the profile. `skillSource` is `jev`, `lexical`, or `null` when skills were skipped.

## memory_search

<ParamField body="query" type="string">

</ParamField>

</ParamField>
<ParamField body="sources" type="string[]">
  Several sources (any of)

</ParamField>
<ParamField body="createdAfter" type="string">
  ISO date or date-time. Only memories created at or after it.
</ParamField>
<ParamField body="createdBefore" type="string">

</ParamField>
<ParamField body="profileId" type="string">

<ParamField body="limit" type="number">
  Max results, 1–100 (default 20)

## memory_retrieve

Retrieve the most relevant memories for a natural language query. Returns scored results with Context Trace.

<ParamField body="query" type="string" required>
  Natural language query
</ParamField>
<ParamField body="type" type="string">
  Filter by memory type
</ParamField>
<ParamField body="tags" type="string[]">
  Filter by tags
</ParamField>
<ParamField body="status" type="string">
  Filter by status (default: active and pinned)
</ParamField>
<ParamField body="profileId" type="string">
  Profile to search in (defaults to active profile)
</ParamField>
<ParamField body="limit" type="number">
  Max results, 1–50 (default 10)
</ParamField>
<ParamField body="threshold" type="number">
  Drop hits whose blended score is below this value (0–1)
</ParamField>
<ParamField body="rerank" type="boolean">
  Optional local extra on the top 20 hits. Skipped when Jev runs. Context Trace
  legs stay on the hit. `"jev"` is an accepted no-op.
</ParamField>
<ParamField body="judge" type="string">
  Jev keep/best is on when `AI_GATEWAY_API_KEY` is set. Pass `off` to skip for
  ablation. Does not 422 without the key.
</ParamField>
<ParamField body="referenceDate" type="string">
  ISO date used as “now” for last-week / currently temporal scoring
</ParamField>

**Returns:** Ranked memories with `trace.scoreBreakdown` (fulltext, vector, chunk, entity, rrf, recency, temporal, confidence, optional rerankerScore / jevRelevant / jevConfidence / jevBest).

See [Context Trace](/concepts/context-trace) for score field details.

## memory_add_batch

<ParamField body="items" type="object[]" required>

  Profile to add to (defaults to active profile)
</ParamField>

**Returns:** `{ profileId, created: [{ index, id, title }], failed: [{ index, error }] }`

## memory_add_instruction

Store memories from natural language. The server uses Vercel AI Gateway to extract atomic facts and creates memories (same pipeline as `POST /api/v1/memories` with `{ "instruction": "..." }`). Requires `AI_GATEWAY_API_KEY`; missing key returns `openrouter_required`.

<ParamField body="instruction" type="string" required>
  What to remember (conversation summary, preferences, decisions, etc.)
</ParamField>
<ParamField body="profileId" type="string">
  Profile to add to (defaults to active MCP profile)
</ParamField>

**Returns:** `{ created: Memory[], summary: string }` or `openrouter_required` if `AI_GATEWAY_API_KEY` is not configured.

## skills_list

List skills granted to this connector: `name`, `description`, `enabled`, `source` (`personal` or `system`), `origin`, `createdAt` and `updatedAt`. No instructions.

<ParamField body="includeDisabled" type="boolean">
  Also list disabled skills and installs (default `false`)
</ParamField>

## skills_import

Personal `/mcp` only. Upsert up to 25 personal skills by exact trimmed name. Idempotent. Sets `origin` to `vibot`. Empty name/description/instructions rows and installed system skill names are skipped.

<ParamField body="items" type="object[]" required>
  `{ name, description, instructions }` rows (max 25)
</ParamField>

**Returns:** `{ created, updated, skipped, names }`

---

## skills_recommend

Shortlist enabled skills that fit a short task. Uses Jev on the AI Gateway when `AI_GATEWAY_API_KEY` is set (same client as retrieve). Fail-open to lexical name/description ranking if the key or Jev is unavailable — the tool does not hard-fail.

<ParamField body="query" type="string" required>
  Short task or question to match against enabled skills
</ParamField>
<ParamField body="limit" type="number">
  Max skills to return, 1–20 (default 8)
</ParamField>

**Returns:** `{ query, source: "jev" | "lexical", skills: [{ name, description, score }] }`

Then call `skills_get` with an exact name for full markdown.
