## What is MCP?

The Model Context Protocol (MCP) is a standard for connecting AI models to external data and tools. vmem uses MCP to provide memory capabilities to any compatible client — Claude, Cursor, Windsurf, and more.

## How vmem Uses MCP

vmem uses MCP primitives differently from most memory tools:

| Primitive     | Standard Usage                       | vmem Usage                                                             |
| ------------- | ------------------------------------ | ---------------------------------------------------------------------- |
| **Resources** | Context injected before LLM responds | Synthesized user profile auto-loaded via `vmem://context_prompt`       |
| **Tools**     | LLM explicitly calls them            | `memory_add`, `memory_search`, `memory_retrieve` — intentional actions |
| **Apps**      | Interactive UI in the host           | `memory_graph` interactive graph                                       |

The key insight: **reading memories is implicit, writing is explicit.**

## MCP Endpoints

```
POST https://<your-deployment>.convex.site/mcp
POST https://<your-deployment>.convex.site/mcp/team
```

Authenticated via Clerk OAuth. See [MCP Setup](/mcp/setup).

Skills, files, and `vmem://context_prompt` used to be personal-only. **Skills tools and `vmem://skills/<name>` resources now work on both connectors**, scoped by grant (personal skills on `/mcp`, team skills on `/mcp/team`). Files tools now work on both connectors too (the active team profile's drive on `/mcp/team`). `vmem://context_prompt` stays personal. Memory tools work on both connectors.

## MCP Resource

| URI                     | Description                                                                      |
| ----------------------- | -------------------------------------------------------------------------------- |
| `vmem://context_prompt` | Synthesized user profile (about, preferences, pinned memories, activity summary) |
| `vmem://skills/<name>`  | Enabled skill playbook (markdown instructions + description). Personal and team. |

`vmem://context_prompt` is personal-connector only. `vmem://skills/<name>` is registered for enabled skills granted to that connector (personal or team). See [Implicit Memory](/mcp/implicit-memory).
