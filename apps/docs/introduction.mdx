## What is vmem?

vmem is a persistent memory layer that lets any AI model store, retrieve, and update user knowledge across sessions and platforms. Instead of each LLM maintaining its own siloed memory, vmem provides a single source of truth that any model can connect to via Convex, HTTP, or MCP.

Hosted app: [vmem-staging.vedantb.com](https://vmem-staging.vedantb.com). Source: [github.com/vvedantb/vmem](https://github.com/vvedantb/vmem).

## The Problem

LLMs lack persistent long-term memory. Users repeatedly provide the same information, rebuild context each session, and lose personalisation when switching between models. Existing solutions like Mem0 and Supermemory are proprietary and tied to specific ecosystems.

## How vmem is Different

### Context Trace

Every memory retrieval explains **why** it matched — with a score breakdown across fulltext, vector, chunk, entity, recency, and graph-neighbour signals. No black-box retrieval.

### Implicit Memory via MCP

Competitors require the LLM to explicitly call tools to fetch memories. vmem injects a synthesized user profile via the `vmem://context_prompt` MCP Resource — relevant context is present before the model responds.

### Memory Lifecycle

Memories can be pinned, suppressed, expired, or audited. Types are `profile`, `episodic`, and `knowledge`.

### Profiles

Organize memories into profiles (personal or team-scoped). Switch profiles when saving or browsing without changing routes.

## Architecture

| Component            | Role                                                          |
| -------------------- | ------------------------------------------------------------- |
| **Convex**           | Auth, memories, API keys, profiles, teams, files, MCP HTTP    |
| **Vite Web App**     | Dashboard for browsing, organizing, and managing memories     |
| **MCP Server**       | Implicit context via Resources, explicit writes via Tools     |
| **Chrome Extension** | Save pages, export chats, inject memories into ChatGPT/Claude |

Memories live in Convex (`memories` table plus links, full-text, and optional vectors). There is no Neo4j runtime. See [Architecture](/architecture).
